# Roro Growth Loop

## Objective
Grow **engaged users/day** with minimal-token, high-leverage execution.

## Primary Metric
- **Engaged users/day (EUD)**
- Initial target: **10 EUD** in first validation phase

## Operating Rule
- One high-leverage action per hour
- One channel at a time
- One message variant at a time
- Stop/continue based on measured signal

## First Micro-Test
- **Channel:** GitHub (zero-friction, immediate distribution)
- **Action:** Improve README positioning + add clear CTA for feedback/discussion
- **Variant A:** "Execution assistant" framing
- **Success signal:** new issue/discussion feedback + repo visits trend up
- **Stop rule:** if no interaction after 24h, switch channel to Reddit or IndieHackers

## Next Candidate Actions
1. Publish public roadmap issue and request votes
2. Add “Good first tasks” board for community contribution
3. Post one build update with concrete before/after outcome
4. Add waitlist/interest form link
