# 90-Day Roadmap

## Days 1-14: Foundation
- Monorepo baseline and service boundaries
- Auth skeleton + user model
- Command ingestion + job queue pipeline
- Basic web control center

## Days 15-30: Core workflows
- Gmail + Calendar integration (read/act)
- Task orchestration and retry logic
- Daily brief generator

## Days 31-60: Reliability + growth
- Observability dashboards (latency/error/queue depth)
- Feedback loops and onboarding improvements
- Public changelog and weekly releases

## Days 61-90: Scale and monetization readiness
- Team workspaces and permissions
- Usage analytics and limits
- Pricing experiment framework (without billing launch)

## KPI checkpoints
- Activation > 55%
- Weekly retention > 35%
- Task success > 97%
- Median command-to-result latency < 8s
