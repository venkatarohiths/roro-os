# Product Brief — Roro OS

## Problem
People use too many disconnected tools and lose time on repetitive coordination work.

## Core Promise
"Tell Roro once. It executes across tools and reports back clearly."

## Target Users (initial)
1. Solo founders/operators
2. Small agencies
3. Power users managing many apps/channels

## JTBD
- Summarize and prioritize communications
- Convert intent into executed tasks
- Track what got done and what is pending
- Keep workflows running with minimal supervision

## MVP Scope
1. Unified command input + action history
2. Integrations: Calendar, Email, GitHub (starter set)
3. Task scheduler and retry pipeline
4. User dashboards: completion rate, response latency, saved time

## Success Metrics (90-day)
- Activation > 55%
- Weekly retention > 35%
- Task success > 97%
- Median command-to-result latency < 8s
